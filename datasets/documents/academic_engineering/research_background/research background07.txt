In recent years, Microservice architecture and cloud-native technologies have become foundational elements in modern enterprise software development, driving the rapid development of distributed systems. [28], [32], [39]. Microservices decompose traditional monolithic applications into independent distributed services, while cloud-native technologies leverage containerization and container orchestration [21] to enhance the capabilities for flexible resource allocation, dynamic scaling, and continuous delivery [30]. In enterprise production environments, microservice systems are composed of numerous independent services and containerized entities [45], which significantly increased system complexity. These systems have intricate inter-service dependencies and communication patterns, where the failure of any component (e.g., network resource corruption) can trigger cascading effects that jeopardize overall system stability, potentially leading to significant economic losses [2]. How to achieve accurate root cause identification and resolution in complex distributed systems has become a key factor in reducing production risks and minimizing losses for modern enterprises.

Root cause analysis aims to quickly correlate related multiple entity features, identify the root cause and determine the corresponding fault type, and provide actionable solutions, thus realizing an automatic fault response mechanism and minimizing human intervention [42]. How to perform an accurate and efficient root cause analysis in the distributed environment has become an important research direction. Traditional RCA methods typically rely on rule-based anomaly detection or statistical correlation analysis (e.g. causal graphs [24]) to localize faults. These methods struggle to jointly analyze heterogeneous data modalities (e.g., unstructured logs and structured metrics), often leading to fragmented information and frequent error detection. DL-based RCA methods attempt to incorporate multimodal feature fusion and dependency-sensitive Graph Neural Networks (GNNs) [23] [44] to achieve accurate fault localization. Although these methods demonstrate good performance in specific tasks such as fault localization in complex systems, they still face significant challenges in real-time analysis and fault interpretability, heavily relying on the expertise of engineers to complete the root cause analysis and remediation process. Recently, large language models have demonstrated revolutionary capabilities in automated root cause analysis, opening new avenues for AIOps [9], [12]. LLM can combine system faults with the current system context to generate actionable fault diagnosis reports, as evidenced by prototypes such as RCACopilot [6]. Recent works such as RCAgent [35] and mABC [43] developed LLM-driven automated RCA frameworks that enable accurate fault localization and provide reasonable repair suggestions, thus further advancing the field of automated operations and maintenance.

However, although existing LLM-based methods have significantly alleviated the reliance on expert knowledge in traditional DL-based methods, they still face the following three key challenges in real distributed system environments: Context Limitations: Limited by fixed-length context windows, the LLM is unable to effectively process massive amounts of contextual monitoring data in real-time. This constraint often leads to data truncation or compression during analysis, making it difficult to utilize historical information to detect anomalous trends in system components, thereby affecting the rationale and accuracy of root cause analysis. So how to extract useful information from the complex system context and input it into the context-limited LLM is a key challenge. Text Input Constraints: Existing large language models such as ChatGPT [1], DeepSeek [27], Qwen [3], etc., either only support text data as input or enable modality input by mapping different modal features to a unified textual semantic space. However, due to the lack of obvious correlation between time series and text, this transformation process often results in a significant loss of key feature information, severely hindering the analytical and reasoning capabilities of LLM. So how to efficiently unify multiple modalities of observation data to assist the LLM in providing accurate root cause analysis results is a key challenge. Dynamic Dependence Hallucination: The LLM is based on static, pre-trained knowledge, which makes it challenging to model service dependencies in systems. It can only simulate simple graph structures using text prompts. As noted in [34], LLMs struggle with reasoning over complex graphs, which limits their ability to effectively capture service dependencies. Additionally, the dynamic nature of service call chains in the system means that evolving dependencies can cause the LLM to generate hallucinations that contradict actual dependencies, leading to inaccurate root cause analysis. So how to assist the LLM in modeling fault propagation paths using call chain relationships to achieve fine-grained root cause localization is a key challenge.

To address these limitations, we propose a tool-assisted LLM agent framework based on domain-specific perceptive models. This framework decouples the LLM from the raw observational data by utilizing specialized observational data analysis tools (T1-T3), addressing the constraints of text input and the limitations of context in the LLM. These specialized model tools are used to perceive the contextual environment, and their results form structured text inputs that are fed back to the RCA expert agent for further analysis, generating accurate root cause analysis results and reasonable maintenance recommendations. Specifically, to address the problem of multimodal data alignment, we propose a dual-branch diffusion model as the data feature observation tool (T1), which unifies multimodal observability data (logs, traces, metrics) into temporally consistent representations. To address the issue of dynamic dependencies, the root cause localization tool (T2) performs a joint analysis of entity features and call topologies, modeling the fault propagation chain, and identifying the root cause through frequency-domain attention-driven temporal causal analysis. Subsequently, the fault classification tool (T3) further analyzes the fault and maps the symptoms to predefined fault types. The main contributions are summarized as follows: We propose a tool-assisted LLM agent framework, which integrates domain-specific model tools with LLMs for root cause analysis of microservices. This framework enables the LLM to analyze the system state in real time by calling perception tools, decoupling the agent from the raw observational data, allowing it to generate accurate root cause analysis results and reasonable maintenance recommendations. We present a dual-branch collaborative diffusion tool that captures potentially consistent patterns across modalities and provides a unified time series representation for downstream analysis tasks through condition-oriented collaborative reconstruction. We design a root cause localization tool based on frequency-domain attention mechanisms, which identifies causal dependency patterns in frequency-domain features while filtering out low-frequency noise, achieving precise root cause localization. Experiments on two benchmark datasets demonstrate that TAMO outperforms all compared methods including state-of-the-art (SOTA) approaches and derived baselines. Ablation and case studies further validate the effectiveness of the framework.
